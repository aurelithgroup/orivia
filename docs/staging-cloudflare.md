# Buddy staging environment

Cloudflare Pages project: `orivia-buddy-preview`.
GitHub branch: `feature/proactive-requirements`.
This site is a development demonstration, not the public Orivia production website.

No real immigration records or identity information should be entered into Buddy Lab. No official immigration decisions are implemented. The Buddy UI remains rules-based and browser-local.

Testing checklist: load site on phone, find Buddy launcher, choose a scenario, answer discovery questions, change action status, reload, open Ask Orivia, change tone, delete saved answers, test offline behavior; verify current sources manually before any real-world use.
